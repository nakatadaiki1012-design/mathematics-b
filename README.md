# 数学Bラボ

数学Bの授業で使える、**図を動かして・見てわかる** Webアプリです。
`index.html` 1 ファイルだけで動きます（インストール不要）。見た目と授業の流れは「数学Aラボ」とそろえています。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/mathematics-b/

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. 上で分野（数列・統計的な推測）をえらび、その下の単元のボタンをおす
3. 右の「導入 → 例題 → 類題 → 応用」を順に進める（「次へ ▶」またはキーボードの →）
4. 応用まで終わると「まとめ」。全部終わった単元には「合格」のはんこ

- **画面はスクロールしなくても全部見える** ように作っています（スマホは上に図、下に説明）。
- 単元ボタンの下の 5 本の線が進み具合です（そのブラウザに保存）。赤い線は演習に合格したしるし。
- URL の最後に `#u-rec/1`（漸化式の例題）、`#rec`（きろく）、`#game`（ゲーム）、`#ta`（タイムアタックをすぐ始める）のように付けると、その画面を開いたリンクになります。
- 右上の「⚙」で文字の大きさ・明るい／暗い画面・全画面（プロジェクター用）・クラス対戦の設定。

## 授業の流れ

| 段階 | すること |
|---|---|
| 導入 | スライダーやボタン、棒のドラッグで図を動かして、しくみを見る |
| 例題 | 「次へ ▶」で 1 ステップずつ、図と式がいっしょに進む |
| 類題 | まず自分で 4 択から答えをえらぶ → 図で解説。「🔁 数字をかえて もう1問」で何度でも |
| 応用 | 少しひねった問題。答えをえらんでから図で解説 |
| 演習 | 数字がかわる 5 問。4 問正解で **合格のはんこ**。✕ の問題だけやり直せる。最高点を記録 |

- まちがえると「💡 ヒント」が出て、もう一度えらべます。
- 上の「式の帯」には、ステップごとの式が **積み上がって**（式の流れ）表示されます。
- 図の右上「↻」で図の動きをもう一度、「✏️」で図に直接書きこめます（赤・青・緑）。
- 「初項」「一般項」「母平均」「棄却」など 点線の下線がついた用語は、タップすると意味が出ます（約 45 語）。

## レベル（右上の 🌱🌿🌳）

| レベル | ちがい |
|---|---|
| 🌱 やさしい | 数が小さい。ヒントが最初から 1 つ出ている |
| 🌿 ふつう | 教科書と同じくらい |
| 🌳 挑戦 | 数が大きい・種類が多い。演習では 4 択ではなく **自分で数字を入力** して答える |

レベルは いつでも切りかえられます。画面の見た目は変わらず、問題の中身だけが変わります。

## 🎮 ごほうび・タイムアタック・クラス対戦（右上の 🎮）

### 🪙 ごほうび（やるほど 段位が上がる）

- コインがたまります：演習の正解 +10・演習の合格 +50（はじめての合格は +150）・タイムアタック 20 点で +1・クラス対戦 参加 +20・3 位以内 +50。
- コインで **段位** が上がります：10級 → 9級 → … → 1級 → 初段 → … → 五段 → **名人**。上がると お祝いが出ます。
- 毎日続けると 🔥 **連続日数**。**バッジ 9 種類**（初合格・全単元制覇・7日連続・10 コンボ・1,000 点・クラス対戦で表彰台 など）。🎮 の画面と「きろく」で見られます。

### ⏱ タイムアタック（ひとりで）

🎮 →「▶ スタート」。60 秒で 数字がかわる問題を 何問とけるか。

- 正しい答えを どんどんタップ（キーボードの 1〜4 でも）。まちがえると コンボが切れます。
- 続けて正解すると **コンボ**。10 コンボごとに 点数が ×1.5 → ×2 → … → ×3。
- 左の図は、その問題の図（ヒント）です。
- 結果は「**9 問を解いた ≒ 教科書の練習問題 1 ページ分**」「≒ 定期テスト 1 回分」のように出ます。「📣 自慢する」で 結果の文章をコピー（スマホなら LINE などへ）。分野 × レベルごとに ベスト記録。
- 分野（数列・統計・全部）とレベル（右上の 🌱🌿🌳）で 問題が変わります。

### 🏆 クラス対戦（リアルタイム）

1. **先生**：🎮 →「🏫 先生：部屋をつくる」。4 けたの **部屋番号** と **QR コード** が出ます（左の大きな画面をプロジェクターに）。分野・単元（習ったところまで）・レベル・時間（30／60／90 秒）をえらべます。
2. **生徒**：QR を読みとる か、🎮 → 部屋番号とニックネームを入れて「参加する」。先生の画面に 名前が 次々ならびます。
3. **先生**：「▶ スタート」。全員の画面で 同時に 3・2・1 → スタート。**全員に同じ順番で同じ問題** が出ます。先生の画面のランキングが **リアルタイムで動きます**（🔥 はコンボ中）。
4. 時間が来ると「🎉 結果発表」。1〜3 位にメダル。生徒の画面には「何位 / 何人中」。
5. 「▶ 第2回戦 スタート」で 何回でも。「🏆 ハイスコア表示」で その部屋の いちばん良い記録。
6. 終わったら「部屋を閉じる」（ランキングも消えます）。

40 人でも ランキングは 1 画面に収まります。

### クラス対戦の準備

はじめから **論理表現ラボと同じデータベース** が設定ずみなので、そのまま使えます（部屋には「数学B」の印がつくので、論理表現ラボの部屋とは混ざりません）。

別のデータベースを使いたいときは、論理表現ラボの README「クラス対戦の準備」と同じ手順で Firebase Realtime Database を作り、右上の ⚙ →「クラス対戦のデータベース」に URL をはりつけて「保存して接続テスト」。生徒は 先生の部屋のリンク・QR から入れば 設定はいりません。

- 無料プランで 同時に つなげるのは 100 台までです（1 クラスなら 十分）。
- 部屋の中身は 部屋番号を知っている人なら 読み書きできます。本名ではなく **ニックネーム** で参加させてください。点数のほかに 個人情報は 送りません。

## 📒 学習のきろく

右上の「きろく」で、全単元の進み具合（導入〜演習）が一覧になります。単元をタップするとそこへ移動。
「🏁 総合演習 10 問」で、分野全体から まぜて出題されます。

## ✏️ 先生モード（図をつくる）

右上の「先生」で、教科書やプリントの **数字をそのまま入れる** と、その数字どおりの図と解説が 1 ステップずつ出ます。

- 「🙈 答えをかくす」：答えのステップを見せずに、生徒に考えさせられる
- 「🔗 リンク」：数字入りのリンクをコピー（例：`#mk/u-arith?a=3&d=4&n=10`）。ブックマークしておけば授業ですぐ開ける
- 「🖨 印刷」：問題と図だけをきれいに印刷
- 図にできない数字（例：公差 0）は、理由を出して自動で直します

| 単元 | 入れられる数字 |
|---|---|
| 等差数列 | 初項・公差・第 n 項 |
| 等差数列の和 | 初項・公差・項数 |
| 等比数列 | 初項・公比・第 n 項 |
| 等比数列の和 | 初項・公比・項数 |
| Σ | 種類（Σk・Σk²・Σ(ak+b)）・a・b・n |
| 階差数列 | 差の種類（等差・×2）・初項・最初の差・差の増え方・第 n 項 |
| 漸化式 | a₁・p・q |
| 数学的帰納法 | 証明する式 |
| 確率分布 | X = 1〜4 の確率 |
| 二項分布 | n・p |
| 正規分布 | 種類・平均・標準偏差・z |
| 母平均の推定 | 信頼度・n・標本平均・σ |
| 仮説検定 | 有意水準・n・表の回数 |

## 単元

| 分野 | 単元 | 図で見えること |
|---|---|---|
| 数列 | 等差数列 | 棒が「+d」ずつのびる。+d の回数は **すきまの数 n − 1** |
| | 等差数列の和 | 階段を **逆さに重ねると長方形** → その半分が和 |
| | 等比数列 | 棒が「×r」ずつのびる。r = 1/2・−2 も |
| | 等比数列の和 | S と rS を **1 つずらして ひくと、両はし以外が消える** |
| | Σ（シグマ） | Σk は階段、Σk² は正方形の面積、Σ(ak + b) は 2 色に分けた棒 |
| | 階差数列 | 数の丸の下に **となりの差** がならぶ（差の差も） |
| | 漸化式 | クモの巣図の **交点 α** と、α からのきょりが p 倍ずつかわる様子 |
| | 数学的帰納法 | **ドミノ**。①（n = 1）と②（k → k+1）のどちらかがないと倒れない |
| 統計的な推測 | 確率分布と期待値 | 棒グラフの **やじろべえ**。つりあう点が E(X)。棒をドラッグできる |
| | 二項分布 | n・p を動かすと山の形が変わる。E = np、σ のはば |
| | 正規分布 | **面積 = 確率**。X の目もりと Z の目もりを上下にならべて標準化 |
| | 母平均の推定 | 30 本の信頼区間をつくって、本当の m をふくむ本数を数える |
| | 仮説検定 | 「ふつう」と仮定した分布の中で、実際の結果がどれくらいめずらしいか |
