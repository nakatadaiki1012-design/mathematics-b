# 数学Bラボ

数学Bの授業で使える、**図を動かして・見てわかる** Webアプリです。
`index.html` 1 ファイルだけで動きます（インストール不要）。見た目と授業の流れは「数学Aラボ」とそろえています。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/mathematics-b/

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. 上で分野（数列・統計的な推測）をえらび、その下の単元のボタンをおす
3. 右の「導入 → 例題 → 類題 → 応用」を順に進める（「次へ ▶」またはキーボードの →）
4. 応用まで終わると「まとめ」。全部終わった単元には「合格」のはんこ

- **画面はスクロールしなくても全部見える** ように作っています（スマホは上に図、下に説明）。
- 単元ボタンの下の 5 本の線が進み具合です（そのブラウザに保存）。赤い線は演習に合格したしるし。
- URL の最後に `#u-rec/1`（漸化式の例題）、`#rec`（きろく）、`#game`（ゲーム）、`#climb`（じっくりチャレンジ）、`#ta`（タイムアタック）のように付けると、その画面を開いたリンクになります。
- 右上の「⚙」で文字の大きさ・明るい／暗い画面・全画面（プロジェクター用）・クラス対戦の設定。

## 授業の流れ

| 段階 | すること |
|---|---|
| 導入 | スライダーやボタン、棒のドラッグで図を動かして、しくみを見る |
| 例題 | 「次へ ▶」で 1 ステップずつ、図と式がいっしょに進む |
| 類題 | まず自分で 4 択から答えをえらぶ → 図で解説。「🔁 数字をかえて もう1問」で何度でも |
| 応用 | 少しひねった問題。答えをえらんでから図で解説 |
| 演習 | 数字がかわる 5 問。4 問正解で **合格のはんこ**。✕ の問題だけやり直せる。最高点を記録 |

- 単元のはじめに **🎯 めあて**（この単元で できるようになること）。まとめで「できたかな？」とふり返ります。
- 段階の右に役わり（「先生といっしょに解く」「自分で解いてみよう」など）が出ます。
- まちがえると、**選んだ答えが なぜちがうか**（例：「12 は 等差数列のように たしている。等比は かける」）が すぐ出て、ヒントを見て もう一度えらべます。
- 解説の最後の「📖 それでもわからないときは（くわしい解説）」で、解き方の流れ全部と **よくあるまちがい** の一覧が見られます（演習でも見られます）。
- 続きからのときは「▶ 前回の続き（類題）から」と出ます。
- はじめて開いたときだけ「👋 ようこそ」の使い方が出ます（⚙ からいつでも見られます）。
- 上の「式の帯」には、ステップごとの式が **積み上がって**（式の流れ）表示されます。
- 図の右上「↻」で図の動きをもう一度、「✏️」で図に直接書きこめます（赤・青・緑）。
- 「初項」「一般項」「母平均」「棄却」など 点線の下線がついた用語は、タップすると意味が出ます（約 45 語）。

## レベル（右上の 🌱🌿🌳）

| レベル | ちがい |
|---|---|
| 🌱 やさしい | 数が小さい。ヒントが最初から 1 つ出ている |
| 🌿 ふつう | 教科書と同じくらい |
| 🌳 挑戦 | 数が大きい・種類が多い。演習では 4 択ではなく **自分で数字を入力** して答える |

レベルは いつでも切りかえられます。画面の見た目は変わらず、問題の中身だけが変わります。

## 🎮 ゲーム（右上の 🎮）：じっくりチャレンジ・タイムアタック・クラス対戦

数学Aラボと同じしくみです。数学は 1 問に時間がかかるので、次々と答えるだけでなく「**1 問を じっくり考える → すぐ答え合わせと解説 → 競争**」を くり返す遊び方を 中心にしています。
ゲームのトップで「📚 範囲」（数列・統計・全部）と「答え方」（🪜 解き方ステップ／答えだけ）をえらびます。

### 🪜 解き方ステップ（はじめから これ）

答えを いきなり 4 択にせず、1 問を **解く順番の 小さな 4 択**（考え方 → 式 → 計算）に分けます。

- **ステップが合うたびに、左の図も 1 段 進みます**（等差数列なら +d の矢印 → 第 n 項の棒、等比数列の和なら rS をずらす → 消える → 和、正規分布なら Z の目もり → 面積 → 答え）。考える順番が 図で見えます。
- いま答えるステップだけ 大きなカード（いまここ）。終わったステップには ✓／✕ と答え。これからのステップは「次のステップ」（前の答えが 見えないように）。
- まちがえても 正しい答えと **「なぜちがうか」**（例：「4 回 は すきまの数は n − 1」）が出て、続けられます。
- 全部合う（完答）と ボーナス。

| 単元 | ステップ |
|---|---|
| 等差数列 | +d を何回？ → 式は？ → 計算 ／ 2 つの項から：すきまは？ → 公差は？ → 初項は？ → 第 8 項は？ |
| 等差数列の和 | 末項は？ → どの列も？（a + l）→ 和の式は？ → 計算 |
| 等比数列 | ×r を何回？ → 式は？ → 計算 ／ 2 つの項から：×r を何回？ → r<sup>k</sup> は？ → r は？ → 初項は？ |
| 等比数列の和 | rS − S で のこるのは？ → (r − 1)S は？ → S は？ |
| Σ | 分けると？ → Σk は？ → 合計 ／ Σk² の公式は？ → n を入れると？ → 計算 |
| 階差数列 | となりの差は？ → 差はどうかわる？ → 差の合計は？ → 第 N 項は？ |
| 漸化式 | α は？ → a<sub>n</sub> − α は どんな数列？ → 一般項は？ |
| 数学的帰納法 | はじめに確かめるのは？ → n = k + 1 の左辺は？ → 整理すると？ |
| 確率分布 | E(X) の求め方は？ → 分子は？ → E(X) は？ |
| 二項分布 | どんな分布？ → E は？ → V は？ ／ 並び方は？ → 1 つの並びの確率は？ → 確率は？ |
| 正規分布 | z は？ → 面積の式は？ → 計算 |
| 母平均の推定 | σ/√n は？ → 1.96 × σ/√n は？ → 信頼区間は？ |
| 仮説検定 | 帰無仮説は？ → 調べる確率は？ → その値は？ → 判定は？ |

問題は 17 種類（数字は毎回かわる）。「答えだけ」にすると、授業の類題と同じ問題に 4 択で答えます。

### 🧗 じっくりチャレンジ（ひとりで・おすすめ）

- 1 問ずつ **考える時間** があります（★ 45 秒・★★ 80 秒・★★★ 120 秒。解き方ステップは 少し長め。短め／ふつう／長め をえらべる）。
- 答えると **すぐ 答え合わせ**。左の図が 解き方の最後まで進み、「📖 くわしく」で 解説も見られます。読み終わったら「次の問題 ▶」（Enter でも）。
- ❤ が 3 つ。まちがえる・時間切れで ❤ −1。**5 問連続正解で ❤ が 1 つ もどる**。
- 点数は **正しさが いちばん大事**：正解なら 500〜1000 点（はやいと 多い）。むずかしい問題ほど・連続正解するほど ふえる。💡 公式を見ると 半分。
- はじめは やさしい問題から。

### ⏱ タイムアタック（ひとりで）

- **時間がなくなるまで続く**（寿司打のしくみ）。正解すると **時間がもどる**（★ むずかしいほど たくさん。ただし 正解するほど 少しずつ へる）。
- まちがえると −3 秒（解き方ステップは −2 秒。続けてまちがえると もっとへる）。5 コンボごとに +3 秒。10 コンボごとに 点数 ×1.5 → … → ×3。
- 問題を読まずに おす「早おし」は 点と時間が へります。
- 持ち時間：おまかせ（解き方ステップ 120 秒・答えだけ 90 秒）／60／120／180 秒。
- 結果は「**9 問を解いた ≒ 教科書の練習問題 1 ページ分**」のように出ます。「📣 自慢」で 結果の文章をコピー。範囲 × 答え方 × 持ち時間ごとに ベスト記録。

### 問題を解く道具

- **💡 公式**：その単元の公式を出せます（使うと 点が半分。タイムアタックは もどる時間も半分）。
- **✏️ 計算メモ**：左の図に 指やペンで書けます（赤・青・緑・けす）。次の問題で 自動でけえます。
- キーボード：1〜4 で答える、Enter で次の問題。

### 📖 終わったあとの解説

ゲームが終わると「📖 まちがえた ○ 問の解説」ボタン。まちがえた問題・時間切れの問題を 1 問ずつ：問題・自分の答えと正解・**解き方ステップの ✓ ✕**・なぜちがうか・解説・公式。「📖 授業『○○』で復習」でその単元へ。「全部」で正解した問題も ふり返れます。

### 🪙 ごほうび（やるほど 段位が上がる）

- コイン：演習の正解 +10・合格 +50（はじめて +150）・タイムアタック 20 点で +1・じっくり 100 点で +1・クラス対戦 参加 +20・3 位以内 +50。
- 段位：10級 → … → 1級 → 初段 → … → 五段 → **名人**。毎日続けると 🔥 連続日数。**バッジ 11 種類**（🪜 ステップ 100・🧗 じっくり 10 問・表彰台 など）。

### 🏆 クラス対戦

先生が「🏫 部屋をつくる」で 4 けたの **部屋番号** と **QR コード** を出し（左の大きな画面を プロジェクターに）、生徒は QR か 部屋番号とニックネームで 参加します。形式は 2 つ。

#### 🎯 クイズ大会（1 問ずつ・はじめから これ）

1. 先生が 範囲・単元（習ったところまで）・レベル・問題数（5／10／15 問）・考える時間（短め／ふつう／長め）をえらんで「▶ スタート」。
2. **先生の画面に 大きな問題と図**、生徒のスマホにも 同じ 1 問。生徒は ▲◆●■ から えらぶ（💡 公式・✏️ 計算メモも使える）。先生の画面には「✋ 回答 ○ / ○ 人」。
3. **全員が答える か 時間切れで 自動で 答え合わせ**：先生の画面に 正解・**それぞれの答えを えらんだ人数**・解き方の図・**まちがえた答えが なぜちがうか**。ここで 先生が 説明できます。生徒のスマホには ✅／❌ と 点数。
4. 「📊 ランキングへ ▶」→ 順位（▲ 上がった人・🔥 連続正解）→「▶ 次の問題」。
5. 最後は「🏁 結果発表」：表彰台（🥇🥈🥉）と「🎯 正確さ」「⚡ コンボ」「📚 正解数」の賞。生徒は まちがえた問題の解説を見られます。
- 先生は「⏩ しめきって 答え合わせ」で 早めに 終わらせることもできます。

#### ⏱ 早とき（全員いっせいの タイムアタック）

1. 先生が 形式で「⏱ 早とき」、答え方（🪜 解き方ステップ／答えだけ）・持ち時間をえらんで「▶ スタート」。
2. 全員の画面で 同時に 3・2・1 → スタート。**全員に同じ問題** が同じ順番で出ます。先生の画面のランキングが リアルタイムで動きます（🔥 はコンボ中）。
3. 正解すると時間がもどるので、終わる時間は 人によってちがいます。先生の画面には「まだプレイ中 ○ / ○ 人」。**全員の時間が切れたら**（または「⏹ ここで結果発表」）「🎉 結果発表」。1〜3 位にメダルと 賞。
4. 「▶ 第2回戦 スタート」で 何回でも。「🏆 ハイスコア」で その部屋の いちばん良い記録。終わったら「部屋を閉じる」。

40 人でも ランキングは 1 画面に収まります。

### クラス対戦の準備

はじめから **論理表現ラボと同じデータベース** が設定ずみなので、そのまま使えます（部屋のデータは `rooms/b〇〇〇〇` に入るので、論理表現ラボ・数学Aラボの部屋とは ぶつかりません）。

別のデータベースを使いたいときは、論理表現ラボの README「クラス対戦の準備」と同じ手順で Firebase Realtime Database を作り、右上の ⚙ →「クラス対戦のデータベース」に URL をはりつけて「保存して接続テスト」。生徒は 先生の部屋のリンク・QR から入れば 設定はいりません。

- 無料プランで 同時に つなげるのは 100 台までです（1 クラスなら 十分）。
- 部屋の中身は 部屋番号を知っている人なら 読み書きできます。本名ではなく **ニックネーム** で参加させてください。点数のほかに 個人情報は 送りません。

## 📒 学習のきろく

右上の「きろく」で、全単元の進み具合（導入〜演習）が一覧になります。単元をタップするとそこへ移動。
「🏁 総合演習 10 問」で、分野全体から まぜて出題されます。

## ✏️ 先生モード（図をつくる）

右上の「先生」で、教科書やプリントの **数字をそのまま入れる** と、その数字どおりの図と解説が 1 ステップずつ出ます。

- 「🙈 答えをかくす」：答えのステップを見せずに、生徒に考えさせられる
- 「🔗 リンク」：数字入りのリンクをコピー（例：`#mk/u-arith?a=3&d=4&n=10`）。ブックマークしておけば授業ですぐ開ける
- 「🖨 印刷」：問題と図だけをきれいに印刷
- 図にできない数字（例：公差 0）は、理由を出して自動で直します

| 単元 | 入れられる数字 |
|---|---|
| 等差数列 | 初項・公差・第 n 項 |
| 等差数列の和 | 初項・公差・項数 |
| 等比数列 | 初項・公比・第 n 項 |
| 等比数列の和 | 初項・公比・項数 |
| Σ | 種類（Σk・Σk²・Σ(ak+b)）・a・b・n |
| 階差数列 | 差の種類（等差・×2）・初項・最初の差・差の増え方・第 n 項 |
| 漸化式 | a₁・p・q |
| 数学的帰納法 | 証明する式 |
| 確率分布 | X = 1〜4 の確率 |
| 二項分布 | n・p |
| 正規分布 | 種類・平均・標準偏差・z |
| 母平均の推定 | 信頼度・n・標本平均・σ |
| 仮説検定 | 有意水準・n・表の回数 |

## 単元

| 分野 | 単元 | 図で見えること |
|---|---|---|
| 数列 | 等差数列 | 棒が「+d」ずつのびる。+d の回数は **すきまの数 n − 1** |
| | 等差数列の和 | 階段を **逆さに重ねると長方形** → その半分が和 |
| | 等比数列 | 棒が「×r」ずつのびる。r = 1/2・−2 も |
| | 等比数列の和 | S と rS を **1 つずらして ひくと、両はし以外が消える** |
| | Σ（シグマ） | Σk は階段、Σk² は正方形の面積、Σ(ak + b) は 2 色に分けた棒 |
| | 階差数列 | 数の丸の下に **となりの差** がならぶ（差の差も） |
| | 漸化式 | クモの巣図の **交点 α** と、α からのきょりが p 倍ずつかわる様子 |
| | 数学的帰納法 | **ドミノ**。①（n = 1）と②（k → k+1）のどちらかがないと倒れない |
| 統計的な推測 | 確率分布と期待値 | 棒グラフの **やじろべえ**。つりあう点が E(X)。棒をドラッグできる |
| | 二項分布 | n・p を動かすと山の形が変わる。E = np、σ のはば |
| | 正規分布 | **面積 = 確率**。X の目もりと Z の目もりを上下にならべて標準化 |
| | 母平均の推定 | 30 本の信頼区間をつくって、本当の m をふくむ本数を数える |
| | 仮説検定 | 「ふつう」と仮定した分布の中で、実際の結果がどれくらいめずらしいか |
